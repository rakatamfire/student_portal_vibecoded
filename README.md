# Student Portal

Created by: Ian Kid A. Sale
Course: Human Computer Interaction
School: Holy Name University

A student portal website made to explore AI-assisted web development.

## Features
- Dashboard with today's classes, grade summary, and deadlines
- Class schedule
- Grades with GPA computation
- Announcements with search and filters
- Student profile

## Tech
HTML, CSS, and JavaScript only. No backend or database.
